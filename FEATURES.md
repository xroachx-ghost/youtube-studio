## 🔧 How It Works

### 1. Script Generation
**Option A: Template (No Setup)**
- Uses intelligent templates
- Structures content professionally
- Works offline

**Option B: Ollama (Better Results)**
- Free local AI (Llama 2)
- Natural language generation
- Customizable and private

### 2. Voiceover (gTTS)
- Google's Text-to-Speech
- 100+ languages supported
- Natural-sounding voices
- No API keys needed
- Unlimited usage

### 3. Video Clips

**Option A: Pexels API (Recommended)**
- Millions of free HD videos
- Professional stock footage
- Free API with generous limits
- No watermarks

**Option B: Generated Backgrounds**
- Colorful, professional backgrounds
- Text overlays
- Works without internet

### 4. Video Assembly (FFmpeg)
- Industry-standard tool
- High-quality encoding (H.264)
- Automatic subtitle burning
- Professional transitions
