## 🔧 Installation & Setup

### Complete Installation

```bash

# Install all dependencies
pip install -r requirements.txt

# Launch GUI
./launch_gui.sh
```

**In GUI:** Settings → API Keys
**Or manually:**
```bash
export ELEVENLABS_API_KEY='your-key'
export PEXELS_API_KEY='your-key'
```

- ElevenLabs: https://elevenlabs.io (2 min)
