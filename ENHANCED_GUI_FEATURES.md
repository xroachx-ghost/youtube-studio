## 📦 Installation

The enhanced GUI is being built in modules for maintainability.

**Current Working Solution:**

While the enhanced GUI is in development, you have FULL FUNCTIONALITY via command line:

```bash
# Ultimate version with ALL features:
python3 main_ultimate_free.py "Your Topic"

# Get ElevenLabs key for best voice:
export ELEVENLABS_API_KEY='your-key'

# Get Pexels for HD videos:
export PEXELS_API_KEY='your-key'
```

**Command line has:**
- ✅ Ultra-realistic voice (9 options)
- ✅ HD stock videos
- ✅ AI scripts
- ✅ YouTube auto-upload
- ✅ Batch processing (via shell scripts)
- ✅ All customization options
